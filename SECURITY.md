# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security issue (such as accidental exposure of credentials or malicious external script injection), please report it responsibly:

1. Do **not** open a public issue.
2. Email the repository maintainers or use GitHub's private vulnerability reporting feature.
3. Provide details of the issue and steps to reproduce.

We appreciate your efforts to responsibly disclose findings and will investigate promptly.
